Support

Route 66 is a free Historic Route 66 companion: named stops, a map that stays on the highway, trip check-ins, and (for the owner) a filming camera. Start in Chicago and drive to Santa Monica, or start at the pier and drive east — From / To on the map flips the corridor.

Common fixes

Near me does nothing. Allow location while using the app. On iPhone: Settings → Route 66 → Location → While Using. On Android: App info → Permissions → Location.

Camera or mic missing on Director’s cut. That screen is owner-only. If you are the owner, allow Camera and Microphone for Route 66, then reopen the cue cards.

Google sign-in opens Safari. That is expected on some iPhones. Finish sign-in there, or use email and a password inside the app.

The map is blank. The phone app loads the live site, so it needs a network. Pull down to retry, or open route66drive.com in a browser.
